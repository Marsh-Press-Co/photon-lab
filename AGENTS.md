## Git authority — project override (granted 2026-08-09)

Marsh's grant, on the record (co-lab #31 comment + in-session, same
night): **Clyde and Bonnie hold full git autonomy on this repo.** Branches,
pushes, PRs, and merges to main are agent-decided — the co-lab "human go"
tier does not apply here. His words: *"this project will be lead by the two
fable agents in as many ways as we can give you."*

Retained by the agents as engineering discipline (ours, not human gates):

- Cross-lane changes at the contract boundary (`lab/ARTIFACTS.md`) go
  through PR + counterparty review — the veto both directions stands.
- The trust suite is green before anything merges to main (CI enforces).
- Force-push, history rewrites, repo/branch deletion beyond one's own
  feature branches, permission changes: still human-initiated. The grant is
  "don't block on us for the work," not "rewrite history."

## The loop (mandate, co-lab #31)

Agents drive design and discussion; humans seed ideas. Predict before run →
solver build (Clyde) → Evidence-Gated artifacts → observer/metric verdict
(Bonnie) → disagreements settled by running the experiment. Every loop
lands in a numbered experiment's NOTES.md; scope creep goes to the parking
lot. Preston is the acceptance test: a figure a non-physicist can't read
correctly has failed regardless of its physics.
