## Steel-man (≤150 words)

Replacing a vocabulary-presence fallback with a physical ratio test is real
progress on exactly my own charter's axis. "State-dependent or coherent
interactions" only earn standing on this bench once reduced to effective
classical parameters, and `gap/(λ/2π)` — built from measurable geometric
quantities (pitch, diameter, λ), not from whether a WebSearch snippet used
the word "localization" — is a legitimate first step toward that reduction.
It is genuinely falsifiable (EM-5's pre-registered failure condition: ratio
≥1 at any bench λ withdraws the classification), it correctly separates
"Bruggeman fit is silent on coupling" from "Bruggeman fit is wrong," and it
is honest about being illustrative pending Phase 4's sourced pitch/diameter
pull rather than the sourced figure itself. It also stays cleanly inside the
Expressibility contract: no σ(I)/gain/dispersive-ε parameter is smuggled
onto the bench, and the cycle scores no constraint metric — a bounded
evidentiary gap-closer, not a mechanism proposal, exactly the register T1
says this cycle should run in.

## Sharpest attack (≤150 words)

"A classical electrodynamics question, not a quantum-optics one" understates
what is actually at stake. `λ/2π` correctly bounds *one* dipole's own
reactive zone, but the load-bearing question — does CNT-forest near-field
coupling bias the Bruggeman-fitted n_eff away from independent-scatterer
Beer–Lambert truth — is a many-body, collective-response question: whether
densely-packed sub-λ coupling is net superradiant (enhanced absorption
cross-section, radiative-damping broadening) or subradiant (dark,
absorption-suppressing modes) is coherent multiple-scattering physics my
charter owns, and this program's own T25/T26 lineage already demonstrated
that a scalar mean-level test can pass cleanly while a large, sign-carrying
effect hides underneath. A binary `ratio<1` confirms coupling *exists*; it
says nothing about which way that coupling would push the cited α, so even
an EM-5-CONFIRMED outcome leaves MP-4's actual mechanism question exactly
where it started, dressed in a better-looking gate. This is not yet
inexpressible — a coupled-dipole/local-field correction factor on σ_eff
would be a legitimate future bench parameter — but Section 5 reads as if the
distance threshold alone settles more than a yes/no "is homogenization
naive" flag, and the proposal's own framing hands away a discipline
boundary (coherent collective response) that is not EM's alone to close.

## Verdict

**Support-with-changes.**

## Parameter change that would flip to full support

Add an explicit, sourced disclosure of *direction*, not just existence, of
the near-field effect: state (even qualitatively, from the classical
coupled-dipole/Clausius–Mossotti/local-field-correction literature — no new
search cost, since Section 5's own query 9 material already exists) whether
tight sub-λ CNT packing is expected to enhance or suppress the ensemble's
effective absorption relative to the independent-scatterer Beer–Lambert
reading the Bruggeman fit assumes, and flag it as unresolved if the
literature snippets available don't decide it. That single addition turns
`ratio<1` from "coupling is real, so the number might be off" into an actual
bound on which way — and how much — it might be off, which is the
sub-claim MP-4 actually needs closed, not merely reopened with a cleaner
instrument.
