## 3. Special standing duty — T18-propagation tripwire check (mandatory, stated regardless of verdict)

**Does exp-062 produce a new verdict-bearing document that would need the `exp061-t18-evidentiary-tier-propagation` caveat?** Yes, near-certainly. exp-062 is explicitly a continuation of exp-061's own MP-3/MP-4 open sub-claim (Section 1: "closes an OPEN sub-claim from exp-061's own MP-4 finding"), restates `α_true≈5.74×10⁴ cm⁻¹` and `graded_black_shell` absorptivity language throughout Section 4, and will produce its own Phase-3 NOTES.md plus (following exp-061's own two-file convention, which this proposal explicitly mirrors — "the same evidentiary posture as exp-036/037/061") a Phase-4 results file. Both documents will state a verdict on the same claim class the registry entry exists to police (EM-2's "confirmed"/EM-4's "reinforces the exclusion" outcomes are exactly this).

**Would `required_sites` need widening?** Yes. As currently scoped, `required_sites=["experiments/061.../NOTES.md","experiments/061.../phase4_results.md"]` — two literal paths, both belonging to exp-061. Neither exp-062's forthcoming NOTES.md nor its forthcoming Phase-4 results file is named, and `candidate_globs` (`LOGBOOK.md`, `PLAN.md`, `experiments/*/NOTES.md`, the one REALIZABILITY_MEMO.md path) would catch exp-062's NOTES.md as a WARN-only candidate but has no pattern that can ever discover a `phase4_results.md`-style file belonging to *any* experiment other than exp-061 by name — the identical structural blind spot Red Team's own audit named for exp-061 itself ("candidate_globs structurally cannot discover it either"), now inherited unfixed by the very next cycle that revisits the same claim.

**Mandatory recommendation for Phase 3, before freeze**: (a) add exp-062's own NOTES.md and its Phase-4 results file (once its filename is fixed) to `exp061-t18-evidentiary-tier-propagation`'s `required_sites`; (b) add a generic `experiments/*/phase4_results.md` glob to that entry's `candidate_globs` (and ideally to `DEFAULT_CANDIDATE_GLOBS`) so this class of gap cannot recur a fourth time under a different experiment number. This is a zero-cost, mechanical fix — no new analysis, just registry maintenance — and doing it now, before Phase 3 freeze, keeps this discovery outside the tripwire's own "after Phase 3 has frozen predictions" firing condition that spared Iteration 38. Doing it *after* freeze would not be spared a second time.
